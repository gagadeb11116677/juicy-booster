# Juicy Booster

Pembersih dan pemantau PC Windows. Gratis.

**[Unduh juicy-booster.exe](https://github.com/gagadeb11116677/juicy-booster/releases/latest/download/juicy-booster.exe)**

Semua versi: https://github.com/gagadeb11116677/juicy-booster/releases

## Cara pakai
1. Unduh file di atas.
2. Klik dua kali.
3. Jika Windows menampilkan peringatan: klik "Info lainnya", lalu "Tetap jalankan".

Untuk fitur lengkap: klik kanan file, pilih "Jalankan sebagai administrator".

## Fitur
Pantau CPU, RAM, disk, jaringan | Bersihkan file sampah | Kelola proses | Atur program startup | Copot aplikasi | Cek ruang disk | Kesehatan baterai dan disk | Atur mode daya

Windows 10 / 11
